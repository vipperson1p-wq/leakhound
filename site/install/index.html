Install LeakHound

Three steps, about two minutes. Everything runs on your machine. You need Node.js 18 or newer.

Step 1

Connect it to your tool

Pick where you write code. The MCP server lets your AI run scans. The skill tells it when to.

Add the MCP server (terminal)
claude mcp add leakhound --scope user -- npx -y leakhound mcp
Install the skill for /leakhound (terminal)
npx leakhound install-skill --user

Start a new Claude Code session so it picks up the server.

Add to .cursor/mcp.json
{
  "mcpServers": {
    "leakhound": {
      "command": "npx",
      "args": ["-y", "leakhound", "mcp"]
    }
  }
}
Install the skill for /leakhound (terminal)
npx leakhound install-skill --cursor

Reload Cursor after saving the file.

Add to claude_desktop_config.json
{
  "mcpServers": {
    "leakhound": {
      "command": "npx",
      "args": ["-y", "leakhound", "mcp"]
    }
  }
}

Restart Claude Desktop after saving the file.

Scan the project
npx leakhound
Include old commits
npx leakhound --history

No AI needed. Run it in your project folder.

Other ways to install
Global — then just run leakhound
npm install -g leakhound
In your project, for teams
npm install -D leakhound

Everyone on the team gets the same version with npm install. The pre-commit hook then runs this local copy: fast and without internet.

Step 2

Run your first scan

Type a command in your AI chat in Claude Code or Cursor. After that, the assistant also scans on its own before commits and after you add keys or write migrations.

  • /leakhoundScan the project and explain every finding in plain words.
  • /leakhound historyAlso search old commits for keys you deleted from files.
  • /leakhound stagedCheck only what goes into your next commit.
  • /leakhound hookInstall the pre-commit hook. Asks you first.
  • /leakhound fixFix critical findings one by one. No critical ones? Turn on RLS for tables it couldn’t verify. Ends with the list of keys to rotate.
No slash commands, e.g. Claude Desktop? Paste this instead, with your project folder: Scan the project in <path to your project> with LeakHound and explain what you find in plain words.

Terminal only? Run npx leakhound, or npx leakhound --history to include old commits.

Step 3

Guard every commit

A git hook checks what you are about to commit and stops it if a key is inside. Works even when you commit without AI.

$npx leakhound install-hook
After installing

LeakHound is free and built in the open. Feedback from real projects is what improves it.

  • Star on GitHubHelps other vibe coders find it.
